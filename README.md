# 📓 Studio Paper

Landing page para uma papelaria fictícia, desenvolvida com **HTML**, **CSS** e **JavaScript** puros. O projeto apresenta uma vitrine de produtos, seção institucional, diferenciais da loja, contato via WhatsApp e localização integrada com Google Maps.

🔗 **Demo:** [GitHub Pages](#) <!-- Cole aqui o link do seu GitHub Pages -->

---

## ✨ Funcionalidades

- Menu de navegação responsivo (com toggle para mobile)
- Catálogo de produtos renderizado dinamicamente via JavaScript
- Feedback visual ao clicar em "Comprar"
- Animações de entrada (*fade-in*) ao rolar a página
- Seção "Sobre" com apresentação da marca
- Contato direto via WhatsApp
- Mapa incorporado com a localização da loja
- Ano do rodapé atualizado automaticamente

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3 (Grid, Flexbox, variáveis CSS, media queries)
- JavaScript (Vanilla JS / DOM)
- Google Fonts (Poppins + Inter)

## 🚀 Como executar localmente

1. Clone o repositório
   ```bash
   git clone https://github.com/seu-usuario/studio-paper.git
   ```
2. Acesse a pasta do projeto
   ```bash
   cd studio-paper
   ```
3. Abra o arquivo `index.html` no navegador (ou use uma extensão como o *Live Server* do VS Code)
